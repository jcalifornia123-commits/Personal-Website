01 / Personal projectInteractive demo available

Human Performance
Analytics Platform

Preparing for an Ironman 70.3 means balancing swimming, cycling, and running with university. I built this platform to put workouts, recovery, sleep, and academic workload on the same timeline.

What I built

A Python/FastAPI backend, a SQLite data model, and a Next.js interface. The original platform brings together WHOOP, Strava, Canvas, and Telegram, with structured check-ins and readiness scoring.

A decision that mattered

I separated provider-specific ingestion from normalized data. That gives the analytics and interface a shared schema, rather than making each view understand every provider.

What you can try

I shipped an account-free demo with a reproducible sample season. Explore training and recovery, compare relationships, and walk through an AI-coach decision without sharing personal health data.

Engineering notes & limits

Keep time in order

The regression code uses a chronological holdout to evaluate predictions. The public demo does not run a trained model, and its sample patterns are not research findings.

Separate the demo from private services

The demo is a static export backed by one deterministic fixture. Its coach uses authored responses and temporary plan changes; live API ingestion and OpenAI tool calling belong to the original backend.
